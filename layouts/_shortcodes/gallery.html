Must use the << delimiter (not %%): with %%, this template's own

Pages using thumbnail galleries should set content_image_widths and content_image_sizes in front matter so the browser selects thumbnail files. {{< gallery class="event-photos" >}} ![Alt text](images/foo.jpg) ![Alt text](images/bar.jpg) {{< /gallery >}} */ -}} {{- $class := .Get "class" | default "" -}}
